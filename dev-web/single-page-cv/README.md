# Single Page CV
https://roadmap.sh/projects/single-page-cv

Um projeto simples de currículo profissional em página única (Single Page CV), desenvolvido com HTML5 semântico e CSS3 modular.

---

## 📌 Sobre o Projeto
Este projeto é um exercício prático de desenvolvimento web focado em:
- Estruturação semântica com HTML5.
- Meta tags e integração Open Graph para pré-visualização em redes sociais.
- Modularização e organização de estilos CSS (`reset.css`, `root.css`, `index.css`).

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 📂 Estrutura de Arquivos

```text
single-page-cv/
```

---

## 🛠️ Como Executar o Projeto / How to Run

Como o projeto é construído apenas com arquivos estáticos (HTML e CSS), não há necessidade de instalação de dependências ou build.

### Opção 1: Abrir diretamente no navegador (Mais simples)
1. Navegue até a pasta do projeto:
   ```bash
   cd dev-web/single-page-cv
   ```
2. Dê um duplo clique no arquivo `index.html` ou abra-o com qualquer navegador (Chrome, Edge, Firefox, etc.).

---

### Opção 2: Usando a extensão Live Server (VS Code / Antigravity)
1. Abra a pasta do projeto no seu editor de código.
2. Clique com o botão direito no arquivo `index.html`.
3. Selecione **"Open with Live Server"**.
4. A página será aberta automaticamente em `http://127.0.0.1:5500`.
